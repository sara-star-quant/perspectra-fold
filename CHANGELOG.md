## [0.1.0] - 2026-01-21

### Added

- Initial project structure with multi-language implementation
- Python research utilities for quantum metrics and dimensionality reduction
- Rust core library with cryptographic primitives (HKDF, cosine similarity)
- Rust gRPC compute service
- Go control plane with HTTP API, telemetry storage, and intelligent routing
- Protocol buffer definitions for inter-service communication
- Comprehensive documentation covering research, architecture, and standards
- CI/CD pipeline with multi-language testing and documentation validation

### Documentation

- Research findings on high-dimensional quantum communication
- Technology stack recommendations
- Zero-trust environment deployment guidance
- Implementation and deployment guides
- ETSI, NIST, and ISO standards compliance overview
- Conformance suite specification and roadmap
